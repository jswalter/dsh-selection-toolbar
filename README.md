# DSH AI 划词工具栏

项目地址：[jswalter/dsh-selection-toolbar](https://github.com/jswalter/dsh-selection-toolbar)。源码、安装器、构建脚本和测试均包含在本仓库，不依赖其他工作区。

macOS 版 DeepSeek Harness 的全局划词插件。DSH 在后台运行且插件启用时，选中文字后显示 **语法修正 / 翻译 / 解释**；点击后展开流式对话，支持追问、复制回答。语法修正和翻译完成后，均可将完整结果替换回原选区。

当前版本：0.1.9（build 11）。安装和加载验证环境为 DSH Desktop **0.2.2-rc.1**；划词引擎和界面行为保持不变。本插件针对 macOS，未实现 Windows/Linux 辅助程序。调研依据见 [RESEARCH.md](RESEARCH.md)。

## 安装与更新

需要 macOS、已初始化的 DeepSeek Harness Desktop、已配置的模型，以及 Apple Command Line Tools（`xcode-select --install` 提供 Swift 编译器）。安装器使用 DSH 自带的 Node 和包管理器，无需另装 Node/npm。

这是公开 GitHub 仓库，下载无需 GitHub 账号。

首次下载：

```sh
git clone https://github.com/jswalter/dsh-selection-toolbar.git
cd dsh-selection-toolbar
sh install.command --dry-run
sh install.command
```

安装前等待 DSH 任务结束并完全退出桌面应用，安装后重新打开。默认通过官方 CLI 安装 `git+https://github.com/jswalter/dsh-selection-toolbar.git#main`；已安装的 JavaScript 位于 DSH profile 的包目录，不链接此源码目录。安装器从**实际安装的包**编译原生应用并执行自检，将完整应用复制到稳定路径，保留原有授权位置。新安装默认使用 `~/.dsh/plugins/selection-toolbar/build/DSH Selection.app`。配置和旧应用会备份到 `$DSH_HOME/backups/local-bundle-selection-*/`。

更新时，退出 DSH 后在本仓库执行：

```sh
git pull --ff-only
sh install.command
```

每次重新安装都会解析 GitHub 的 `main`，并重新编译实际下载的版本。也可不保留源码，直接运行 DSH 已安装包内的入口：

```sh
sh "${DSH_HOME:-$HOME/.dsh}/profiles/desktop/node_modules/dsh-selection-toolbar/install.command"
```

插件管理页可以更新 JavaScript 包；涉及原生源码时，仍需退出 DSH 并运行上述安装入口，确保 `.app` 同步更新。失败信息会给出本机备份目录；编译失败时旧辅助应用和配置保持原样，但包可能已经更新，可重新运行安装器完成同步。

非默认应用位置使用 `DSH_APP_PATH='/实际位置/DeepSeek Harness.app'`，自定义配置目录传 `--home '/实际 DSH_HOME'`。`--dry-run` 只预览；`--local` 可供开发时改用本仓库的 `link:`，常规安装不要传此参数。

首次运行时，在“系统设置 → 隐私与安全性 → 辅助功能”允许安装预览中 `helperPath` 所属的 `DSH Selection.app`。已有授权路径会保留；系统若因重新签名要求授权，移除旧条目并重新添加实际应用。无需屏幕录制、摄像头或麦克风权限。新安装使用通用应用标识；升级已有应用时读取并保留其标识，以兼容已有授权。

## 使用

1. **仅按住鼠标左键拖拽框选文字后触发**。双击、三击、Shift＋点击、键盘选择（包括 ⌘A、Shift＋方向键）和普通打字均不会唤出工具栏；键盘输入会隐藏已有的未展开工具栏。选区稳定后约 0.6 秒显示三个按钮，需要复制回退时可能稍慢。工具栏左边贴近选区左边缘，优先位于上方，空间不足时换到下方或侧面并限制在屏幕内。复制取词时使用按下/松开事件记录的框选区域，鼠标移走后保持原锚点，不再扩成整行或编辑区宽度。工具栏不抢走原应用焦点。
2. 点击操作才发送文字，选文以 `<selection>` 标签包装后发给模型，追问保持原样，模型不会把选文中的请求当作对它的指令。语法修正按上下文纠正错别字（尤其是拼音输入法的同音、近音词）、语法和标点，并做简单润色，保留原意、语言、口吻、专名、代码和格式，只输出完整修正稿。翻译面板提供原始语言与目标语言，支持简体中文、繁体中文、英语和日语；原始语言另有“自动检测”，初始默认自动检测 → 简体中文，手动选择会保存。从工具栏点击“翻译”且原始语言为自动检测时，默认中英互译：检测到的语言与目标语言相同时，中文（简繁）改译为英语，英语或日语改译为简体中文，面板上的目标语言随之切换但不保存。手动更改语言才会重新翻译，且不再自动切换；手动把原始语言和目标语言设为同一种语言时，不调用模型，直接输出原文。明确指定原始语言后可交换两种语言。解释用简体中文，按单词、句段、代码等类型调整内容，默认简短。
3. 浮窗中可继续提问，或说明进一步修改要求。回答默认按 Markdown 渲染，支持标题、粗体、斜体、删除线、列表、引用、链接、代码块及表格；普通文本正常显示，流式回答会持续更新排版。每轮回答独立解析。“复制回答”和“替换原文”使用最后一轮的原始 Markdown，保留井号、星号、代码围栏等格式标记。“重新生成”按原选区开启新一轮对话。
4. 在工具栏/回答面板的“··· → 划词设置”，或菜单栏“划词 → 划词设置”中切换模型。默认跟随 DSH 当前默认模型；下拉列表直接读取所有已注册服务商的模型，包括外接服务商，按“服务商 · 模型名”区分同名项。可刷新列表，选择保存在本机。切换模型后点击“重新生成”生效。为缩短等待，采用所选模型支持的最低思考等级；不修改 DSH 全局默认等级。
5. 语法修正或翻译完整成功后，可点击“替换原文”。程序先核对原应用、可编辑控件、原窗口和仍选中的原文，能读取全文与 UTF-16 范围时同时核对它们，再执行编辑器原生粘贴并核实结果。原文已变、焦点指向别的控件、选区超过 15 分钟、回答失败/取消/截断时不会替换。
6. 工具栏高 42 点，回答面板宽 400 点，短回答自动收缩，最高 352 点；长内容内部滚动。界面跟随系统明暗模式；回答面板顶部整条标题区可拖动，标题文字不支持框选，图钉和关闭按钮仍可点击。点外部关闭，图钉可固定面板。关闭浮窗会停止当前请求；菜单栏“划词”可暂停/恢复监控、刷新模型目录或退出辅助程序。辅助程序随 DSH 插件停用或宿主退出而结束；从菜单退出后，通过重启 DSH 恢复。

## 兼容边界

- 全局取词支持 `AXSelectedText`、选区范围与文本值、富文本控件及网页祖先的 text marker；应用未公开焦点时，尝试系统焦点并核对进程归属。读取不到选文时，普通文本控件和网页文本区域也可在明确选择手势后临时复制取词，不再仅限 VS Code；不会定时触发复制。图片、扫描 PDF、画布及不支持复制的控件仍可能无法取词，本版不做 OCR。同一次拖选内，辅助功能接口读到的选区连续两次一致即锁定，之后不再反复读取，下一次鼠标或键盘操作才重新取词；长选区在 Outlook 等 WebKit 邮件正文中偶尔读取超时，也不会因此收回工具栏。每次拖选最多尝试读取 6 次，避免无响应的应用持续拖慢辅助程序。
- 主动请求前台 Electron 应用开启 `AXManualAccessibility`，VS Code 除外。VS Code 始终使用原生复制并校验 `vscode-editor-data`，排除空选区复制整行、多光标和块选择；无需扩展或屏幕阅读器优化，`editor.accessibilitySupport` 可保持 `off`。其他应用若提供相同标记，也执行上述排除规则。
- 替换要求可编辑控件及可核实的原选区，不再强制要求全文或可写范围接口。保留选区的网页/Electron 输入框可以使用原生粘贴；原选区丢失时，仅在完整原文未变且支持范围写入的情况下恢复选区。只读网页正文不提供永久写回。
- 原生复制取词会临时使用剪贴板，保存全部格式，并在没有新的用户操作或剪贴板改动时恢复。通过此路径取词时，替换前再次复制核对原选文。粘贴后只读取应用公开的文本来核验，不再逐字反选或再次复制结果；取消原先 4,000 字符的反选验证限制。应用无法提供可核实的结果时，关闭回答面板，菜单栏短暂显示“已发送替换”，悬停说明需要检查原文；不会抢回焦点、声称核验成功或自动重试。
- 使用发送给原应用的 `Command+V`，不通过 `AXSelectedText` 直接写入：部分 Electron 编辑器会报告 AX 写入成功却不修改文档。粘贴前临时保存全部剪贴板类型，只有剪贴板没有被用户再次更改时才恢复；保留编辑器自身的撤销行为。不重写整篇文稿，不在写回结果不明时自动重试。
- 密码控件和常见密码管理器被排除。只读取当前前台应用的焦点子树、有限层级祖先和选择手势命中的元素；缺少焦点控件时限于当前焦点窗口，不扫描后台窗口。网页祖先的选区只有在 text marker 两端均属于编辑控件时才允许写回该控件。
- 选区上限 24,000 个 UTF-16 单元，追问上限 8,000，最多 24 轮；每次请求 120 秒超时、8,192 输出 token。超限会说明原因，不静默截断后替换。
- 同时开启其他划词工具可能出现多个浮窗，可按需要关闭其他工具的划词功能。

## 数据与实现

- DSH Cordis Host 插件通过受支持的 `ctx.llm.prepareCall` 调用已配置模型，不自行读取或复制 API Key。
- OpenCode（Zen / Go）请求自动携带 `x-opencode-session`，同一划词对话及其追问复用会话 ID，重新生成或重新划词时使用新 ID。兼容内置服务商和指向 `opencode.ai` 及其子域名的自定义接口；已有同名请求头保留。自定义接口的补充请求头使用 DSH 0.2.2-rc.1 的公开请求头事件，仅作用于本插件的对话。
- 回答区使用 WebKit 和随应用打包的 markdown-it 14.1.0，离线解析；不执行回答中的 HTML，不自动加载远程图片（显示图片说明）。点击普通网页链接时由系统浏览器打开。Markdown 渲染不改变模型提示词、思考深度或原始回答；依赖来源与许可证见 `native/Markdown/THIRD_PARTY.md`。
- Swift/AppKit 辅助程序通过私有 stdin/stdout 管道与插件通信，不监听 HTTP 端口。选区只在辅助程序内暂存，点击操作才传给插件和模型；不提供模型工具，也不执行选中文字或模型返回的命令。
- 提交后的请求与回答保存在 `~/.dsh/selection-toolbar/conversations/*.jsonl`（目录 0700、文件 0600）。记录包含选中文本与追问，便于核对请求；不会写入本源码目录，不会自动删除。对话记录独立于 DSH 主聊天列表，浮窗关闭后不能从插件界面恢复，可从 JSONL 查阅。
- `~/.dsh/selection-toolbar/status.json` 保存最近一次权限、连接、暂停状态及前台应用标识，用于诊断；不包含选中文字或回答。
- 源码：`engine.mjs` 管理模型请求和对话，`index.mjs` 管理生命周期和管道，`native/ClipboardSelection.swift` 管理原生复制及剪贴板标记校验，`native/Selection.swift` 管理选区与替换，`native/main.swift` 管理浮窗、模型设置和权限说明，`native/Appearance.swift` 管理颜色、图标按钮、表面绘制与追问文字居中，`native/MarkdownView.swift` 和 `native/Markdown/` 管理 Markdown 显示。
- 手动执行 `sh scripts/build.sh` 会将应用写入本目录 `build/`，缓存默认放在 `build/.cache/`；可通过 `DSH_SELECTION_TMP` 指定缓存目录。GitHub 安装器在本机备份目录内临时构建，成功复制后清理临时产物。源码仓库不提交编译产物。

## 验证与卸载

```sh
sh scripts/test.sh
sh scripts/build.sh
'build/DSH Selection.app/Contents/MacOS/DSHSelection' --self-test
sh install.command --uninstall --dry-run
sh install.command --uninstall
```

命令行卸载通过官方 CLI 移除插件包注册及本插件配置覆盖；也可直接在 DSH 插件管理器卸载。不删除源码、对话、备份和辅助应用；需要永久删除这些本地资料时请自行处理。详细已验证范围记录在 [VALIDATION.md](VALIDATION.md)。
